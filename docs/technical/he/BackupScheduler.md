# תיאור מחלקה: BackupScheduler

## 1. מידע כללי
*   **שם המחלקה:** `BackupScheduler`
*   **סוג:** מחלקה רגילה (Utility)
*   **מטרה:** מחלקה זו פועלת כ"מתכננת". היא אומרת למערכת אנדרואיד מתי ואיך לבצע את הגיבוי.
*   **אינטראקציות:** מתקשרת עם `MainActivity` (כדי להתחיל) ועם `BackupJobService` (אותו היא מתזמנת).

## 2. משתנים (שדות המחלקה)
| שם | סוג | מטרה | היכן בשימוש |
| :--- | :--- | :--- | :--- |
| `JOB_ID` | `int` | מספר זיהוי ייחודי למשימה זו (נקבע ל-1). | לרישום המשימה במערכת. |

## 3. מתודות המחלקה
### שם המתודה: `scheduleBackup`
*   **מה היא עושה:** 
    1. יוצרת "כרטיס" (`ComponentName`) עבור `BackupJobService`.
    2. מחשבת את הזמן עד השעה 01:00 בלילה הקרובה.
    3. מגדירה חוקים: הרצה כל 24 שעות, שמירה לאחר אתחול המכשיר, ודרישת חיבור לרשת.
    4. מגישה את הבקשה למזכירות המערכת `JobScheduler`.
*   **מתי נקראת:** ידנית מתוך `MainActivity.onCreate()`.

## 8. הסבר מפושט
**"הסבר במילים פשוטות"**
חשבו על `BackupScheduler` כעל **שעון מעורר**. אתם לא אלו שקמים לעבוד; אתם רק מכוונים את השעון עבור ה"עובד" (`BackupJobService`) שיתעורר ב-01:00 ויבצע את העבודה רק אם התנאים מתאימים.
