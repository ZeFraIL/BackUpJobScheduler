# Описание класса: MainActivity

## 1. Общая информация
*   **Имя класса:** `MainActivity`
*   **Тип:** Activity (Активность/Экран)
*   **Назначение:** Это точка входа в приложение. Главная задача — инициализировать приложение и запустить процесс планирования фоновой задачи резервного копирования.
*   **Взаимодействие:** Вызывает класс `BackupScheduler` для настройки задачи.

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `TAG` | `String` | Метка для логирования (вывод сообщений в консоль для разработчика). | В `Log.d` или `Log.e` для идентификации источника сообщения. |

## 3. Методы класса
### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Возвращаемое значение:** `void` (ничего не возвращает)
*   **Параметры:**
    | Имя | Тип | Описание |
    | :--- | :--- | :--- |
    | `savedInstanceState` | `Bundle` | Содержит данные из предыдущей сессии (если приложение было закрыто и открыто снова). |
*   **Что делает:** 
    1. Вызывает родительскую версию `onCreate`.
    2. Устанавливает визуальный макет с помощью `setContentView`.
    3. Вызывает `BackupScheduler.scheduleBackup(this)` для запуска логики фонового копирования.
*   **Когда вызывается:** Автоматически системой Android при запуске приложения.
*   **Что важно понимать:** Этот метод должен быть быстрым. Если поместить сюда тяжелую работу, экран останется белым или зависнет.

## 4. Жизненный цикл
*   **onCreate():** Вызывается при первом создании активности. Здесь мы создаем «скелет» экрана и заводим таймер бэкапа.

## 5. Взаимодействие с интерфейсом (UI)
*   **Элементы:** Использует `activity_main.xml`.
*   **Связь:** Связь осуществляется через `setContentView`. Здесь нет кнопок, так как приложение работает автоматически в фоне.

## 7. Общая логика
Когда пользователь нажимает на иконку приложения, `MainActivity` просыпается, загружает главный экран и сразу говорит системе: «Эй, пожалуйста, убедись, что наша база данных будет скопирована в 1:00 ночи».

## 8. Упрощенное объяснение
**«Объяснение простыми словами»**
Представьте, что `MainActivity` — это **кнопка включения** на кофемашине. Когда вы её нажимаете, машина загорается и автоматически проверяет, не пора ли запустить цикл очистки (задачу бэкапа). Сама кнопка кофе не варит, она просто запускает процесс.
