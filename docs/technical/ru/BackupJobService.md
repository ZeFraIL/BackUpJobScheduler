# Описание класса: BackupJobService

## 1. Общая информация
*   **Имя класса:** `BackupJobService`
*   **Тип:** `JobService` (Сервис задач)
*   **Назначение:** Это «Рабочий». Он выполняет реальное копирование файла базы данных из приватной папки приложения в публичную папку.
*   **Взаимодействие:** Управляется системным `JobScheduler`. Читает файл внутренней БД и записывает во внешнее хранилище.

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `DB_NAME` | `String` | Имя файла базы данных. | Поиск исходного файла. |
| `BACKUP_DIR` | `String` | Имя папки для копий. | Создание пути назначения. |

## 3. Методы класса
### Имя метода: `onStartJob`
*   **Тип:** `public`
*   **Что делает:** Запускает новый **Поток** (Thread — отдельный путь выполнения), чтобы копирование файла не «заморозило» основное приложение.
*   **Когда вызывается:** Системой, когда наступают условия (время, сеть).

### Имя метода: `backupDatabase`
*   **Тип:** `private`
*   **Логика:** Находит путь к БД, создает папку в «Документах» и переносит данные байт за байтом.
*   **Важно:** Копирование — это тяжелая операция ввода-вывода (I/O), поэтому она ОБЯЗАТЕЛЬНО должна быть в отдельном потоке.

## 8. Упрощенное объяснение
**«Объяснение простыми словами»**
Представьте, что `BackupJobService` — это **ночной уборщик**. Пока офис (приложение) закрыт, уборщик заходит, берет папку из картотеки (база данных), делает ксерокопию и кладет её в сейф на складе (внешняя память). Когда закончит, оставляет записку: «Я всё сделал».
