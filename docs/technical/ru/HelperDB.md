# Описание класса: HelperDB

## 1. Общая информация
*   **Имя класса:** `HelperDB`
*   **Тип:** `SQLiteOpenHelper`
*   **Назначение:** Этот класс управляет созданием и структурой локальной базы данных приложения.
*   **Взаимодействие:** Используется другими частями приложения для сохранения или получения данных о машинах.

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `DB_FILE` | `String` | Имя файла базы на диске ("all_cars.db"). | Система использует это для создания файла. |
| `TABLE_CARS` | `String` | Название таблицы внутри БД. | В SQL-запросах. |

## 3. Методы класса
### Имя метода: `onCreate`
*   **Что делает:** Запускает команду **SQL** (язык запросов к базам данных) для создания таблицы «Cars», если её еще нет.
*   **Когда вызывается:** Самый первый раз, когда приложение пытается обратиться к базе.

## 8. Упрощенное объяснение
**«Объяснение простыми словами»**
Представьте, что `HelperDB` — это **архитектор** и **библиотекарь**. Архитектор решает, сколько полок (таблиц) будет в библиотеке и какие этикетки (колонки) будут на книгах. Библиотекарь следит, чтобы библиотека была построена правильно, прежде чем туда положат первую книгу.
