# Описание класса: BackupScheduler

## 1. Общая информация
*   **Имя класса:** `BackupScheduler`
*   **Тип:** Обычный класс (Утилита)
*   **Назначение:** Этот класс работает как «Планировщик». Он сообщает системе Android, когда и как должно быть выполнено резервное копирование.
*   **Взаимодействие:** Взаимодействует с `MainActivity` (для запуска) и `BackupJobService` (который он планирует).

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `JOB_ID` | `int` | Уникальный идентификационный номер для этой конкретной задачи (равен 1). | Для регистрации задачи в системе. |
| `TAG` | `String` | Используется для идентификации в системных логах. | В `Log.d` для отображения успешного планирования. |

## 3. Методы класса
### Имя метода: `scheduleBackup`
*   **Тип:** `public static`
*   **Параметры:** `context` (`Context`) — данные окружения для доступа к системным сервисам.
*   **Что делает:** 
    1. Создает «билет» (`ComponentName`) для `BackupJobService`.
    2. Вычисляет время до следующего часа ночи (01:00).
    3. Устанавливает правила: запускать каждые 24 часа, сохранять после перезагрузки, требовать любую сеть.
    4. Передает запрос системному секретарю `JobScheduler`.
*   **Когда вызывается:** Вручную из `MainActivity.onCreate()`.

### Имя метода: `getNextExecutionTime`
*   **Тип:** `private static`
*   **Что делает:** Вычисляет ровно сколько миллисекунд осталось до 01:00 ночи. Если час ночи уже прошел сегодня, планирует на завтра.

## 8. Упрощенное объяснение
**«Объяснение простыми словами»**
Представьте, что `BackupScheduler` — это **будильник**. Вы не тот, кто встает работать; вы просто ставите будильник для «Рабочего» (`BackupJobService`), чтобы он проснулся в час ночи и сделал работу, только если телефон на зарядке или есть интернет.
